# SimpleGrid – Programm-Symbol

Das Symbol stammt aus dem Branding-Paket von SimpleGrid (`branding/`, Master: `simplegrid-master.svg`):
ein grünes Blatt mit Eselsohr und einem 3×3-Raster.

- `simplegrid.svg` ist eine Kopie des Masters.
- Alle PNG-Größen, `hicolor/…` und `simplegrid.ico` (für Programm und Installer) erzeugt
  `python installer/symbol_erzeugen.py` aus derselben Geometrie.

Farben: Verlauf `#18C58A` → `#078653`, Eselsohr `#6EE7B7`, Felder weiß.
